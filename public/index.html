          For agents and developersx402 · curl · network
          

            
Any agent can pay. This returns 402 Payment Required with the USDG terms:


curl -i -X POST <origin>/api/ask \
  -H 'content-type: application/json' \
  -d '{"question":"latest block?"}'


# from a clone of the repo: signs, pays, prints the answer and the tx
npm run buy -- "latest block?"

            
    
              
  1. The endpoint answers 402 with the price in USDG.
    2. 
              
  2. The wallet or agent signs one EIP-3009 authorization. No gas, no approve.
    3. 
              
  3. Ultravioleta's open-source x402 facilitator settles it on chain.
    4. 
              
  4. The call is served.
    5. 
            

            
This page sends your wallet address (X-Payer) before the 402, so the server can quote the holder price.
